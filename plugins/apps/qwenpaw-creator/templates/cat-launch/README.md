# 猫咪新品发布会 · 一张照片

Creator 用户模板，ID：`user:cat_launch_v1`。输入一张猫咪照片，使用已配置的视频模型生成约15秒的白棚新品发布短片，再通过现有字幕和合成能力导出 MP4。

## 安装

将本目录的 `user_cat_launch_v1.json` 复制到正在运行的 Creator 数据目录下的 `user-templates/`，保留文件名。数据目录由运行环境的 `CREATOR_DATA_ROOT` 指定；QwenPaw 插件模式通常使用 QwenPaw 工作目录下的 `creator-runtime/`。不要复制到插件源码的 backend 目录。若目标已有同名自定义模板，请先备份。

刷新 Creator 的新建项目页面，选择「猫咪新品发布会 · 一张照片」。此仓库目录用于分发用户模板，不会自动注册为内置模板；本机实验环境已经安装。

## 使用

上传一张清晰、无文字、无水印、非拼图的猫咪原照，脸部、眼睛和主要花纹可见，然后发送：

> 请用这张猫咪照片，按「猫咪新品发布会 · 一张照片」模板，自动制作一条15秒的猫咪发布会视频，配好字幕和声音并导出成片。

模板要求直接图生视频，以原照锁定身份，不额外生成角色身份板或逐镜分镜图。外观来自用户图片，不绑定猫咪品种、毛色或眼色。当前配置的模型必须支持15秒图生视频及所需音频能力。图生视频输出受首帧比例影响；横幅照片更适合五猫并排，竖幅也可使用。

| 目标时间 | 画面 |
|---|---|
| 0–2.5秒 | 白棚全身亮相，自然眨眼 |
| 2.5–5秒 | 毛发与侧脸近景 |
| 5–7.5秒 | 单眼微距 |
| 7.5–10秒 | 抬爪轻触镜头 |
| 10–13秒 | 同一猫咪的五套虚拟穿搭 |
| 13–15秒 | 产品式收尾与治愈短句 |

`caption-styles.json` 是六组字幕配置的可读副本，同样的配置已嵌入模板的 `design_floor_body` 中；安装只需要主模板 JSON。字幕使用现有 `OverlayCreation.motion` 的 HTML/CSS 配置，透明底、深灰无衬线字、英文眉题及短淡入。更新样式时应同时更新主模板中的副本。

## 实测与边界

已在 Windows、Creator 1.3.0、wan3.0-video-prime 上用单张本地猫照完成15秒、720×1280、有音轨的真实生成、自动入库和字幕合成。需要本分支包含的 Windows file URL 解析与视频二进制读写修复。此前失败的同一项目通过现有重试入口继续，未手工替换生成素材。

模板由 Creator Agent 解释创作要求，不是新增工作流执行代码。现有执行授权和素材审阅设置保持生效，需要确认时确认后继续；不能将其视为无审批无人值守。模型不保证精确到秒的切镜，字幕应按实际镜头边界核对；竖幅穿搭阵列可能拥挤。尚未验证任意猫照的成功率。

此目录仅包含模板配置和说明，不包含用户照片、生成视频、项目运行数据或模型凭据。
